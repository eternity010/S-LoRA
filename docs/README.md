# S-LoRA 文档目录

本目录包含 S-LoRA 项目的各类文档。

## 目录结构

### `design/` - 设计文档（历史归档）

包含项目早期的设计方案和技术分析文档，已完成实施。

- **数据并行实现方案.md** - 数据并行模式的详细实现方案
- **SLora数据并行与优化.md** - 张量并行 vs 数据并行对比分析

这些文档记录了系统的设计思路和决策过程，可作为历史参考。

### `changelog/` - 开发记录（历史归档）

包含各个开发阶段的代码修改记录和 Bug 修复记录。

- **Phase1-代码修改记录.md** - Phase 1 详细修改记录
- **Phase1-代码修改记录-精简版.md** - Phase 1 精简版记录
- **BUGFIX_BATCH_MERGE.md** - Batch 合并相关 Bug 修复记录

记录了数据并行功能开发过程中的代码变更和实现细节。

## 当前活跃文档

项目根目录下的文档为当前活跃使用的文档：

- **论文思路整理.md** - 论文结构和核心思路
- **优化方向详解.md** - 未来可能的优化方向
- **README.md** / **README_CN.md** - 项目说明
- **debug.md** - 调试记录
- **PROJECT_STRUCTURE.md** - 项目结构说明

## 文档维护

- 已完成实施的设计文档归档到 `docs/design/`
- 已完成阶段的开发记录归档到 `docs/changelog/`
- 当前工作相关的文档保留在项目根目录
- 重要的历史决策和设计思路应保留在归档文档中
